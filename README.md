## ⚡ Key Features

- **Cinematic Experience**: Immersive digital workspace aesthetic with deep industrial dark-mode elements and neon accents.
- **GSAP Animations**: Complex scroll-driven animations, parallax effects, and smooth reveal transitions utilizing GSAP and ScrollTrigger.
- **Custom Cursor & Interactions**: Magnetic buttons, custom cursor rings, and 3D tilt effects for an engaging user experience.
- **Fully Responsive**: Flawless execution across all devices, from ultra-wide monitors to mobile screens.
- **Zero-Dependency Core**: Built with Vanilla HTML, CSS, and JavaScript for maximum performance and complete control over the DOM.
- **Glassmorphism UI**: Sophisticated frosted glass effects for depth and visual hierarchy.

## 🛠️ Technology Stack

- **Structure**: Semantic HTML5
- **Styling**: Advanced Vanilla CSS (Custom Properties, CSS Grid/Flexbox, Animations)
- **Logic & Interactions**: Vanilla JavaScript (ES6+)
- **Animation Engine**: [GSAP](https://greensock.com/gsap/) (GreenSock Animation Platform) + ScrollTrigger

## 🚀 Getting Started Locally

Since this is a vanilla web project, running it locally is extremely straightforward:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/deviljerry/MY-PORTFOLIO.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd MY-PORTFOLIO
   ```
3. **Run the project:**
   Simply open `index.html` in your favorite web browser, or use a local development server like VS Code's Live Server for hot-reloading.
   ```bash
   npx serve .
   ```
